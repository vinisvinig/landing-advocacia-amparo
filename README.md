# Amparo Advocacia Trabalhista: landing page conceitual

Conceito de landing page para um escritório fictício de advocacia trabalhista em Gravataí e Porto Alegre (RS), feito como peça de portfólio.

**Ver online:** https://vinisvinig.github.io/landing-advocacia-amparo/

- Ideia central: "advocacia trabalhista depois do expediente", para quem trabalha o dia todo e não consegue ir ao escritório
- Filme automático "uma noite comum": relógio de 17:58 a 21:49, com fotos, frases e a conversa com a advogada
- Caixa de conversa fixa no lugar do botão genérico de WhatsApp, com status pela hora de Brasília
- Áreas em lista tipográfica com foto que segue o mouse, equipe em arcos, endereços em tipografia grande
- HTML, CSS e JavaScript puros, num único arquivo (imagens e fontes embutidas); versão para celular

Escritório, pessoas, endereços e contatos são fictícios. Fotos: [Pexels](https://www.pexels.com).
